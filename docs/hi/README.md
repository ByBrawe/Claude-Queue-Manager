# Claude Queue Manager (QM) — उपयोगकर्ता मार्गदर्शिका

[🌐 Hindi / हिन्दी](../languages/README.md) · [GitHub](https://github.com/ByBrawe/Claude-Queue-Manager) · [MIT](../../LICENSE)

QM, Claude Desktop के **Code** टैब या Claude Code CLI में कार्यों की कतार बनाता है। पिछला मुख्य टर्न खत्म होने पर ही अगला कार्य अलग टर्न में शुरू होता है; चल रहे काम को बीच में नहीं बदलता।

## “जारी रखो”

`जारी रखो` सामान्य कार्य-पाठ है, QM का कोई विशेष कमांड नहीं। `/qm repeat` जैसे कमांड अंग्रेज़ी में ही रहते हैं, लेकिन कार्य किसी भी भाषा में लिख सकते हैं।

```text
/qm repeat 5 जारी रखो
```

## इंस्टॉल करना

नीचे के दो कमांड से मार्केटप्लेस और प्लगइन इंस्टॉल करें। फिर नया लोकल **Code** सत्र खोलें या `/reload-plugins` चलाएँ। सामान्य Chat टैब समर्थित नहीं है।

```text
/plugin marketplace add ByBrawe/Claude-Queue-Manager
/plugin install qm@claude-queue-manager
```

## सुरक्षित शुरुआत

पहले कतार रोकें, कार्य जोड़ें, `/qm` में क्रम देखें, फिर दोबारा शुरू करें।

```text
/qm pause
/qm batch फेल हुए टेस्ट ठीक करो || बिल्ड चलाओ || बदलावों का सार दो
/qm
/qm resume
```

## कमांड

| /qm | कमांड |
| --- | --- |
| `/qm` | कतार पैनल खोलें |
| `/qm add जारी रखो` | एक कार्य जोड़ें |
| `/qm repeat 5 जारी रखो` | एक ही कार्य 1–200 बार जोड़ें |
| `/qm batch A \|\| B \|\| C` | अलग-अलग कार्य क्रम से जोड़ें |
| `/qm front जारी रखो` | कार्य को सबसे पहले रखें |
| `/qm pause  /qm resume` | रोकें / फिर शुरू करें |
| `/qm mv 3 1` | प्रतीक्षा में कार्य 3 को स्थान 1 पर ले जाएँ |
| `/qm edit 2 जारी रखो` | प्रतीक्षा में कार्य 2 संपादित करें |
| `/qm rm 2` | प्रतीक्षा में कार्य 2 हटाएँ |
| `/qm undo` | पिछला परिवर्तन पूर्ववत करें |
| `/qm clear` | केवल प्रतीक्षारत कार्य साफ़ करें |
| `/qm recover` | क्रैश के बाद अधूरा कार्य वापस लाएँ और कतार रोकें |
| `/qm help` | सहायता देखें |

## सीमाएँ और सावधानियाँ

एक बार में अधिकतम **200 कार्य** और कुल **500 प्रतीक्षारत कार्य**। हर कार्य मॉडल कोटा और कॉन्टेक्स्ट उपयोग कर सकता है; 200K कॉन्टेक्स्ट हर टर्न पर अपने आप रीसेट नहीं होता। स्पष्ट समाप्ति-शर्त के बिना 'जारी रखो' बार-बार न भेजें। उत्तर मिलना सफलता का प्रमाण नहीं है।

## समस्या समाधान

`/qm` न दिखे तो प्लगइन जाँचें और नया लोकल **Code** सत्र खोलें। दूसरे queue प्लगइन बंद रखें; पहले दो छोटे कार्यों से जाँचें।
