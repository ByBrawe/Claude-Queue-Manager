# Claude Queue Manager (QM) — Посібник користувача

[🌐 Ukrainian / Українська](../languages/README.md) · [GitHub](https://github.com/ByBrawe/Claude-Queue-Manager) · [MIT](../../LICENSE)

QM додає завдання до черги в Claude Desktop (**Code**) або Claude Code CLI. Кожне завдання запускається окремим кроком після завершення попереднього, не змінюючи поточну роботу.

## “продовжуй”

`продовжуй` — звичайний текст завдання, а не спеціальна команда. Ключові слова `/qm` лишаються англійською, але текст завдання може бути будь-якою мовою.

```text
/qm repeat 5 продовжуй
```

## Встановлення

Встановіть marketplace і плагін командами нижче. Потім відкрийте нову локальну сесію **Code** або виконайте `/reload-plugins`. Звичайний Chat не підтримується.

```text
/plugin marketplace add ByBrawe/Claude-Queue-Manager
/plugin install qm@claude-queue-manager
```

## Безпечний початок

Призупиніть чергу, додайте завдання, перевірте порядок через `/qm`, після чого відновіть виконання.

```text
/qm pause
/qm batch Виправ тести з помилками || Запусти збірку || Підсумуй зміни
/qm
/qm resume
```

## Команди

| /qm | Команди |
| --- | --- |
| `/qm` | Відкрити панель черги |
| `/qm add продовжуй` | Додати завдання |
| `/qm repeat 5 продовжуй` | Повторити завдання 1–200 разів |
| `/qm batch A \|\| B \|\| C` | Додати різні завдання по черзі |
| `/qm front продовжуй` | Поставити завдання на початок |
| `/qm pause  /qm resume` | Призупинити / відновити |
| `/qm mv 3 1` | Перемістити завдання 3 на позицію 1 |
| `/qm edit 2 продовжуй` | Змінити завдання 2 в очікуванні |
| `/qm rm 2` | Видалити завдання 2 в очікуванні |
| `/qm undo` | Скасувати останню зміну |
| `/qm clear` | Очистити лише завдання в очікуванні |
| `/qm recover` | Відновити завдання після збою і призупинити чергу |
| `/qm help` | Показати довідку |

## Обмеження та застереження

Не більше **200 завдань за один раз** і **500 в очікуванні**. Кожне завдання використовує ліміти моделі й контекст; новий крок не очищає автоматично контекст 200K. Не повторюйте « продовжуй » без зрозумілої умови завершення. Відповідь не гарантує успіх.

## Усунення проблем

Якщо `/qm` не видно, перевірте плагін і відкрийте нову локальну сесію **Code**. Вимкніть інші менеджери черги та спершу перевірте двома короткими завданнями.

### ZIP

Розпакуйте ZIP, залиште папку `Claude-Queue-Manager` у постійному місці та виконайте:

```sh
claude plugin marketplace add /absolute/path/to/Claude-Queue-Manager
claude plugin install qm@claude-queue-manager
```

> Примітка: перекладено лише посібник; інтерфейс панелі QM залишається англійським.
