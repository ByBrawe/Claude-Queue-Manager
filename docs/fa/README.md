# Claude Queue Manager (QM) — راهنمای کاربر

[🌐 Persian / فارسی](../languages/README.md) · [GitHub](https://github.com/ByBrawe/Claude-Queue-Manager) · [MIT](../../LICENSE)

QM کارها را در بخش **Code** برنامه Claude Desktop یا Claude Code CLI صف‌بندی می‌کند. هر کار پس از پایان نوبت قبلی در نوبتی جداگانه اجرا می‌شود و کار در حال انجام را تغییر نمی‌دهد.

## “ادامه بده”

`ادامه بده` متن معمولی یک کار است، نه دستور ویژه QM. نام دستورهایی مثل `/qm repeat` انگلیسی می‌ماند، اما متن کار را می‌توان به هر زبانی نوشت.

```text
/qm repeat 5 ادامه بده
```

## نصب

با دو دستور زیر مخزن افزونه و خود افزونه را نصب کنید. سپس یک نشست محلی جدید در **Code** باز کنید یا `/reload-plugins` را اجرا کنید. بخش معمولی Chat پشتیبانی نمی‌شود.

```text
/plugin marketplace add ByBrawe/Claude-Queue-Manager
/plugin install qm@claude-queue-manager
```

## شروع ایمن

ابتدا صف را متوقف کنید، کارها را اضافه کنید، ترتیب را با `/qm` بررسی کنید و سپس ادامه دهید.

```text
/qm pause
/qm batch تست‌های ناموفق را اصلاح کن || بیلد را اجرا کن || تغییرات را خلاصه کن
/qm
/qm resume
```

## دستورها

| /qm | دستورها |
| --- | --- |
| `/qm` | باز کردن پنل صف |
| `/qm add ادامه بده` | افزودن یک کار |
| `/qm repeat 5 ادامه بده` | تکرار یک کار از ۱ تا ۲۰۰ بار |
| `/qm batch A \|\| B \|\| C` | افزودن چند کار به ترتیب |
| `/qm front ادامه بده` | قرار دادن کار در ابتدای صف |
| `/qm pause  /qm resume` | توقف موقت / ادامه |
| `/qm mv 3 1` | جابه‌جایی کار سوم به جایگاه اول |
| `/qm edit 2 ادامه بده` | ویرایش کار دوم در صف |
| `/qm rm 2` | حذف کار دوم در صف |
| `/qm undo` | برگرداندن آخرین تغییر |
| `/qm clear` | پاک کردن فقط کارهای منتظر |
| `/qm recover` | بازیابی کار پس از خرابی و توقف صف |
| `/qm help` | نمایش راهنما |

## محدودیت‌ها و نکات

در هر بار حداکثر **۲۰۰ کار** و در مجموع **۵۰۰ کار منتظر** مجاز است. هر کار می‌تواند سهمیه مدل و فضای متن را مصرف کند؛ با هر نوبت جدید، فضای 200K خودکار پاک نمی‌شود. «ادامه بده» را بدون شرط پایان روشن بارها تکرار نکنید. پاسخ مدل به معنی موفقیت قطعی نیست.

## رفع مشکل

اگر `/qm` دیده نمی‌شود، فعال بودن افزونه را بررسی کرده و نشست محلی **Code** تازه‌ای باز کنید. افزونه‌های صف دیگر را غیرفعال کنید و ابتدا با دو کار کوتاه امتحان کنید.

### ZIP

فایل ZIP را استخراج کنید، پوشه `Claude-Queue-Manager` را در مسیری ثابت نگه دارید و سپس اجرا کنید:

```sh
claude plugin marketplace add /absolute/path/to/Claude-Queue-Manager
claude plugin install qm@claude-queue-manager
```

> توجه: این راهنما ترجمه شده است، اما رابط پنل QM همچنان انگلیسی است.
