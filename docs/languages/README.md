## Change the interface language

Use the language selector at the top of the native panel or web dashboard. In Claude Code, use `/qm lang <code>`, for example:

```text
/qm lang tr
/qm lang en
/qm lang de
/qm lang pt-BR
/qm lang zh-CN
```

The native/CLI preference is saved across restarts. The web dashboard saves its own preference per browser origin; choosing a documentation link does not change the running interface. First use defaults to Turkish; a saved preference is preserved. Arabic and Persian use right-to-left layout in the web dashboard.

Command names, task contents and host-supplied diagnostics are not translated. Additional-language controls use concise localized labels.

## Arayüz dilini değiştir

Native panelin veya web panelinin üstündeki dil menüsünü kullan. Terminalde `/qm lang <kod>` yazabilirsin. Dil seçimi rehber bağlantısından bağımsızdır. Native/CLI tercihi yeniden başlatmada korunur; web tercihi tarayıcıda ayrıca saklanır. İlk kullanım dili Türkçedir; daha önce kaydedilmiş tercih değiştirilmez. Komut adları ve görev metinleri çevrilmez.
