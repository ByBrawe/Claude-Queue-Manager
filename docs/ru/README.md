# Claude Queue Manager (QM) — Руководство пользователя

[🌐 Russian / Русский](../languages/README.md) · [GitHub](https://github.com/ByBrawe/Claude-Queue-Manager) · [MIT](../../LICENSE)

QM ставит задачи в очередь в Claude Desktop (**Code**) или Claude Code CLI. Каждая задача запускается отдельным ходом после завершения предыдущего, не вмешиваясь в текущую работу.

## “продолжай”

`продолжай` — обычный текст задачи, а не специальная команда. Ключевые слова `/qm` остаются английскими, но саму задачу можно написать на любом языке.

```text
/qm repeat 5 продолжай
```

## Установка

Установите marketplace и плагин командами ниже. Затем откройте новую локальную сессию **Code** или выполните `/reload-plugins`. Обычная вкладка Chat не поддерживается.

```text
/plugin marketplace add ByBrawe/Claude-Queue-Manager
/plugin install qm@claude-queue-manager
```

## Безопасный старт

Поставьте очередь на паузу, добавьте задачи, проверьте порядок через `/qm`, затем возобновите.

```text
/qm pause
/qm batch Исправь падающие тесты || Запусти сборку || Кратко опиши изменения
/qm
/qm resume
```

## Команды

| /qm | Команды |
| --- | --- |
| `/qm` | Открыть панель очереди |
| `/qm add продолжай` | Добавить одну задачу |
| `/qm repeat 5 продолжай` | Повторить задачу 1–200 раз |
| `/qm batch A \|\| B \|\| C` | Добавить разные задачи по порядку |
| `/qm front продолжай` | Поставить задачу в начало |
| `/qm pause  /qm resume` | Приостановить / возобновить |
| `/qm mv 3 1` | Переместить задачу 3 на позицию 1 |
| `/qm edit 2 продолжай` | Изменить ожидающую задачу 2 |
| `/qm rm 2` | Удалить ожидающую задачу 2 |
| `/qm undo` | Отменить последнее изменение |
| `/qm clear` | Очистить только ожидающие задачи |
| `/qm recover` | Вернуть незавершённую задачу после сбоя и поставить паузу |
| `/qm help` | Показать справку |

## Ограничения и предупреждения

Не более **200 задач за раз** и **500 ожидающих задач**. Задачи расходуют лимиты модели и контекст; новое сообщение не очищает окно контекста 200K автоматически. Не повторяйте « продолжай » без понятного условия завершения. Ответ модели не гарантирует успех.

## Решение проблем

Если `/qm` не отображается, проверьте плагин и откройте новую локальную сессию **Code**. Отключите другие плагины очереди; сначала протестируйте две короткие задачи.

### ZIP

Распакуйте ZIP, сохраните папку `Claude-Queue-Manager` в постоянном месте и выполните:

```sh
claude plugin marketplace add /absolute/path/to/Claude-Queue-Manager
claude plugin install qm@claude-queue-manager
```

> Примечание: переведено только руководство; интерфейс панели QM остаётся английским.
