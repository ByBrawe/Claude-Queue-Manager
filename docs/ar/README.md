# Claude Queue Manager (QM) — دليل الاستخدام

[🌐 Arabic / العربية](../languages/README.md) · [GitHub](https://github.com/ByBrawe/Claude-Queue-Manager) · [MIT](../../LICENSE)

يدير QM قائمة انتظار المهام في علامة **Code** داخل Claude Desktop أو في Claude Code CLI. تبدأ كل مهمة في دور مستقل بعد انتهاء الدور السابق، دون تغيير المهمة الجارية.

## “تابع”

`تابع` نص عادي يُرسل إلى Claude، وليس أمرًا خاصًا في QM. تبقى كلمات الأوامر مثل `/qm repeat` بالإنجليزية، ويمكن كتابة نص المهام بأي لغة.

```text
/qm repeat 5 تابع
```

## التثبيت

ثبّت سوق الإضافات والإضافة باستخدام الأمرين أدناه. ثم افتح جلسة **Code** محلية جديدة أو نفّذ `/reload-plugins`. علامة Chat العادية غير مدعومة.

```text
/plugin marketplace add ByBrawe/Claude-Queue-Manager
/plugin install qm@claude-queue-manager
```

## بدء آمن

أوقف قائمة الانتظار مؤقتًا، وأضف المهام، وتحقق من ترتيبها عبر `/qm`، ثم استأنف التنفيذ.

```text
/qm pause
/qm batch أصلح الاختبارات الفاشلة || شغّل البناء || لخّص التغييرات
/qm
/qm resume
```

## دليل الأوامر

| /qm | دليل الأوامر |
| --- | --- |
| `/qm` | فتح لوحة قائمة الانتظار |
| `/qm add تابع` | إضافة مهمة واحدة |
| `/qm repeat 5 تابع` | تكرار مهمة من 1 إلى 200 مرة |
| `/qm batch A \|\| B \|\| C` | إضافة مهام مختلفة بالترتيب |
| `/qm front تابع` | وضع مهمة في المقدمة |
| `/qm pause  /qm resume` | إيقاف مؤقت / استئناف |
| `/qm mv 3 1` | نقل المهمة المنتظرة 3 إلى الموضع 1 |
| `/qm edit 2 تابع` | تعديل المهمة المنتظرة 2 |
| `/qm rm 2` | حذف المهمة المنتظرة 2 |
| `/qm undo` | التراجع عن آخر تغيير |
| `/qm clear` | مسح المهام المنتظرة فقط |
| `/qm recover` | استعادة مهمة بعد تعطل التطبيق ثم إيقاف القائمة مؤقتًا |
| `/qm help` | عرض المساعدة |

## الحدود والتنبيهات

الحد الأقصى **200 مهمة في كل إضافة** و**500 مهمة منتظرة** إجمالًا. قد تستهلك كل مهمة حصة النموذج وسياقه، ولا يبدأ كل دور بسياق 200K فارغ تلقائيًا. لا تكرر «تابع» كثيرًا دون شرط توقف واضح. رد النموذج لا يضمن نجاح المهمة.

## استكشاف الأخطاء

إذا لم يظهر `/qm` فتحقق من تفعيل الإضافة وافتح جلسة **Code** محلية جديدة. عطّل إضافات قوائم الانتظار الأخرى، وجرّب مهمتين قصيرتين أولًا.

### ZIP

فكّ ضغط ZIP، واترك مجلد `Claude-Queue-Manager` في مكان ثابت، ثم شغّل:

```sh
claude plugin marketplace add /absolute/path/to/Claude-Queue-Manager
claude plugin install qm@claude-queue-manager
```

> ملاحظة: تُرجمت هذه التعليمات فقط، أما واجهة لوحة QM فما زالت بالإنجليزية.
